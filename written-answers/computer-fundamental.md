7. **(b) What is register? What are the common register found in a basic computer?** *[BPSC (Ministry of Power, Energy & Mineral Resources) Assistant Director (ICT) (CS/CSE) 29.05.2025 compact it 1356 (ET: N/A)]*


   Answer:

   What a register is:
   - A register is a very small, very fast storage location inside the CPU itself, used to hold data, an address or an instruction while it is being processed. It is the fastest storage in the memory hierarchy, faster than cache and main memory, but there are only a few of them and each holds only a word.

   Common registers in a basic computer:
   - Accumulator, AC: holds one operand and the result of arithmetic and logic operations performed by the ALU.
   - Program Counter, PC: holds the address of the next instruction to be fetched.
   - Instruction Register, IR: holds the instruction currently being decoded and executed.
   - Memory Address Register, MAR: holds the memory address from which data is to be read or to which it is to be written.
   - Memory Buffer Register, MBR, also called the Memory Data Register: holds the data just read from or about to be written to memory.
   - Data Register, DR: holds the operand read from memory.
   - Address Register, AR: holds the address of the operand in memory.
   - Temporary Register, TR: holds intermediate values during a computation.
   - Input Register and Output Register, INPR and OUTR: hold a character coming from an input device or going to an output device.
   - Status or Flag Register, PSW: holds condition flags such as zero, carry, sign and overflow.
   - Stack Pointer, SP: holds the address of the top of the stack.
   - General purpose registers, R0 to Rn, available to the programmer for any purpose.
8. **1TB = কত বাইট?** *[BPSC Ministry of Women and Children Affairs Computer Trainer 2021 compact it 944 (ET: N/A)], [BARI Assistant Maintenance Engineer 15.11.2025 compact it 1451 (ET: N/A)]*


   Answer: 1 TB equals 1,000,000,000,000 bytes in the decimal system and 1,099,511,627,776 bytes in the binary system.

   - Decimal, the SI convention used by disk manufacturers: 1 TB = 10¹² bytes = 1,000 GB.
   - Binary, the convention used by operating systems: 1 TB = 2⁴⁰ bytes = 1024 GB = 1,099,511,627,776 bytes. Strictly this quantity should be called a tebibyte, TiB.
   - This is why a disk sold as 1 TB shows about 931 GB in Windows: the manufacturer counted in powers of ten and the operating system counts in powers of two.
   - The chain: 1 KB = 1024 bytes, 1 MB = 1024 KB, 1 GB = 1024 MB, 1 TB = 1024 GB.

   Answer:

   What a computer generation means:
   - A computer generation is a stage in the development of computers, marked by the electronic component used to build the processor and the resulting change in size, speed, cost and reliability. Each generation represents a fundamental change in technology rather than a mere improvement.

   Characteristics of the generations:

   | Generation | Period | Main component | Characteristics |
   |---|---|---|---|
   | First | 1940 to 1956 | Vacuum tube | Very large and heavy, filling a room; enormous power consumption and heat; magnetic drum memory; programmed in machine language; very expensive and unreliable. Examples: ENIAC, UNIVAC, EDVAC |
   | Second | 1956 to 1963 | Transistor | Much smaller, faster, cheaper and more reliable than tubes; less heat; magnetic core memory; assembly language and early high level languages such as FORTRAN and COBOL. Examples: IBM 1401, IBM 7094 |
   | Third | 1964 to 1971 | Integrated Circuit, IC | Many transistors on one chip, so far smaller and faster; keyboard and monitor replaced punched cards; operating systems allowed multiprogramming and time sharing; high level languages became standard. Examples: IBM 360, PDP-8 |
   | Fourth | 1971 to present | Microprocessor, that is LSI and VLSI | Thousands and then millions of transistors on one chip; the personal computer became possible; GUI, mouse, networks and the Internet; semiconductor memory; very cheap and very reliable. Examples: IBM PC, Apple Macintosh, and every modern PC and laptop |
   | Fifth | Present and future | ULSI and Artificial Intelligence | Parallel processing, natural language input, learning and reasoning, expert systems, speech and image recognition, robotics; research into quantum and optical computing. Languages: Prolog, LISP |

   - The overall trend across the generations: size, cost and power consumption fall steeply, while speed, storage capacity and reliability rise steeply.
12. **Write short note : SMTP, RIP, RDBMS, ITSQN** *[Sheikh Kamal IT Training & Incubation Center Assistant Programmer/Instructor 04.08.2023 compact it 599 (ET: N/A)]*


   Answer:

   SMTP, Simple Mail Transfer Protocol:
   - The application layer protocol used to send and relay email, running over TCP port 25, and port 587 for client submission. It is a push protocol that carries the message from the sender's client to the sender's mail server and then from one mail server to the next, using the commands HELO, MAIL FROM, RCPT TO, DATA and QUIT. It is not used to receive mail; POP3 or IMAP does that.

   RIP, Routing Information Protocol:
   - A distance vector interior gateway routing protocol that uses the Bellman-Ford algorithm. Its metric is hop count, with a maximum of 15, so 16 means unreachable. It broadcasts its whole routing table to its neighbours every 30 seconds. It uses split horizon, route poisoning and hold-down timers to limit routing loops. It is simple but slow to converge, so it is used only in small networks. Administrative distance 120.

   RDBMS, Relational Database Management System:
   - Software that stores data in tables of rows and columns and manages the relationships between them, based on Codd's relational model. It enforces primary and foreign keys, supports SQL, and guarantees the ACID properties of atomicity, consistency, isolation and durability. Examples: Oracle, MySQL, PostgreSQL, Microsoft SQL Server.

   ITSQN:
   - The abbreviation as written does not correspond to a standard computing term, and it appears to be a transcription error in the question paper. The nearest standard terms are ITSM, IT Service Management, that is the practice of designing and delivering IT services, of which ITIL is the best known framework; and ISQN, which is not a recognised computing abbreviation. <!-- verify -->

17. **What is OCR? Write down the difference between OCR and OMR.** *[NPCBL Junior Assistant Manager (ICT) 2022 compact it 642 (ET: BUET)]*


   Answer:

   What OCR is:
   - OCR stands for Optical Character Recognition. It is the technology that converts an image of text, such as a scanned document, a photograph or a PDF, into machine readable and editable text.
   - It works by scanning the image, segmenting it into lines, words and individual characters, comparing each character shape against known patterns or classifying it with a trained neural network, and finally applying a dictionary and language model to correct the result.
   - Uses: digitising printed books and records, reading passports and national identity cards, automatic number plate recognition, cheque processing in banks, and converting scanned files into searchable PDFs.

   Difference between OCR and OMR:

   | Point | OCR | OMR |
   |---|---|---|
   | Full form | Optical Character Recognition | Optical Mark Recognition |
   | What it reads | The shapes of printed or handwritten characters | The presence or absence of a mark in a predefined position |
   | Output | Actual text that can be edited and searched | Which box was filled, that is a selected option |
   | Complexity | High, it must recognise thousands of character shapes | Low, it only detects light and dark in fixed positions |
   | Accuracy | Very good for clean printed text, weaker for handwriting | Extremely high, effectively error free |
   | Speed | Slower | Very fast |
   | Special paper | Not required, any document will do | A pre-printed form with marked positions is required |
   | Examples | Digitising a book, reading a passport, number plate recognition | MCQ answer sheets, survey forms, lottery tickets, ballot papers |

   - A third related technology is MICR, Magnetic Ink Character Recognition, used on bank cheques, which reads characters printed in magnetic ink and is almost impossible to forge.

19. **Write short notes on: (i) RAM (ii) ROM (iii) Primary key (iv) Foreign key (v) Data** *[BPSC (Ministry of Home Affairs) Assistant Database Administrator (ICT) 2022 compact it 671 (ET: N/A)]*


   Answer:

   (i) RAM, Random Access Memory:
   - The main working memory of a computer, in which the operating system, the running programs and the data currently in use are held.
   - It is volatile, so everything is lost when the power is switched off, and it is read and write.
   - Any location can be reached in the same time, which is what random access means.
   - Two types: SRAM, which uses flip flops, is very fast and expensive and is used for cache; and DRAM, which uses capacitors, needs periodic refreshing, and is cheaper and denser, so it is used for main memory.

   (ii) ROM, Read Only Memory:
   - Non-volatile memory whose contents survive a power failure, used to hold firmware such as the BIOS and the bootstrap program.
   - It is normally read only in operation, so the essential start-up code cannot be altered accidentally.
   - Types: PROM, written once by the user; EPROM, erasable by ultraviolet light; and EEPROM and flash memory, erasable electrically, which is what modern BIOS chips and SSDs use.

   (iii) Primary key:
   - A column, or a combination of columns, that uniquely identifies each row of a table.
   - It cannot be NULL and cannot contain duplicates, and a table may have only one primary key.
   - It automatically creates a unique index, so lookups by the key are fast.
   - Example: `student_id` in a `Student` table. A key made of more than one column is called a composite key, and a candidate key not chosen as the primary key is an alternate key.

   (iv) Foreign key:
   - A column in one table whose values must match the primary key of another table, which is how a relationship between the two tables is expressed.
   - It enforces referential integrity: a row cannot refer to a parent row that does not exist, and a parent row cannot be deleted while children refer to it, unless ON DELETE CASCADE or SET NULL is specified.
   - It may contain NULL and may contain duplicate values, and a table may have many foreign keys.
   - Example: `department_id` in an `Employee` table referring to `department_id` in a `Department` table.

   (v) Data:
   - Raw, unorganised facts and figures that by themselves carry no meaning, such as numbers, characters, symbols, images or signals.
   - When data is processed, organised and given context it becomes information, and information understood and applied becomes knowledge.
   - Example: `85`, `90`, `78` are data; "the average mark of the class is 84.3" is information.

21. **What is first programming language?** *[BARC Data Entry Officer 10.09.2022 compact it 703 (ET: N/A)]*


   Answer: FORTRAN, developed by John Backus at IBM in 1957, is generally regarded as the first high level programming language.

   - Its name stands for FORmula TRANslation, and it was designed for scientific and engineering calculation. It is still used today for high performance numerical computing.
   - Two qualifications worth stating:
   - Plankalkül, designed by Konrad Zuse between 1942 and 1945, was theoretically the first high level language, but it was never implemented at the time, so it had no practical influence.
   - Before FORTRAN, programming was done in machine language, which is the binary code the processor executes directly, and then in assembly language, which uses mnemonics such as ADD and MOV.
   - Other early languages: LISP in 1958 for artificial intelligence, and COBOL in 1959 for business data processing.
   - Ada Lovelace is credited with writing the first algorithm intended for a machine, in 1843, which is why she is called the first programmer, but that was not a programming language.

23. **Write short answer on the following: (a) Plaintext (b) HTTP (c) Gateway used in \underline{\phantom{\text{Network}}} layer. (d) VIRUS full form (e) Who is the father of Computer? (f) What is Cyber security? (g) What is Malware? (h) Write the IEEE standards WiFi and WiMax. (i) Write two HTML empty tag.** *[CAAB Assistant Maintenance Engineer (AME) 2022 compact it 724 (ET: N/A)]*


   Answer:

   (a) Plaintext:
   - The original readable message before encryption, or the message after it has been decrypted. Its encrypted form is called ciphertext. In web terms, data sent over HTTP travels as plaintext and can be read by anyone in the path, which is why HTTPS is used.

   (b) HTTP:
   - HyperText Transfer Protocol, the application layer protocol that carries web pages and resources over TCP port 80. It is a stateless request and response protocol; cookies or sessions are needed to maintain state. Its main methods are GET, POST, PUT and DELETE.

   (c) A gateway is used in which layer:
   - A gateway can operate at any layer of the OSI model, and it is most often described as working at the Application layer, layer 7, because it performs protocol conversion, which may require the whole message to be rebuilt in another format. In everyday LAN usage the phrase default gateway refers to a router interface, which works at the Network layer, layer 3.

   (d) VIRUS full form:
   - Vital Information Resources Under Seize.

   (e) Who is the father of the computer:
   - Charles Babbage, for designing the Difference Engine and the Analytical Engine in the nineteenth century. Alan Turing is called the father of computer science and artificial intelligence, and John von Neumann is credited with the stored program architecture used by every modern computer.

   (f) What is cyber security:
   - The practice of protecting computers, networks, programs and data from unauthorised access, damage or disruption. Its three core objectives are confidentiality, integrity and availability, known as the CIA triad. It covers network security, application security, endpoint security, identity and access management, encryption, incident response and user awareness.

   (g) What is malware:
   - Malicious software written to damage, disrupt or gain unauthorised access to a computer system. Its types include viruses, which attach to a host program; worms, which spread by themselves; Trojans, which disguise themselves as legitimate software; ransomware, which encrypts data and demands payment; spyware and keyloggers, which steal information; adware; rootkits, which hide deep in the system; and botnets.

   (h) IEEE standards for Wi-Fi and WiMAX:
   - Wi-Fi is IEEE 802.11, with amendments a, b, g, n which is Wi-Fi 4, ac which is Wi-Fi 5, ax which is Wi-Fi 6 and be which is Wi-Fi 7.
   - WiMAX is IEEE 802.16, with 802.16e being the mobile version.

   (i) Two empty HTML tags:
   - `<br>`, which inserts a line break, and `<img>`, which inserts an image. Other empty, that is self closing, tags are `<hr>`, `<input>`, `<meta>` and `<link>`. An empty tag has no closing tag and no content.

26. **“Copy and Paste” এর উদ্ভাবক কে?** *[BWMRI Assistant Maintenance Engineer 2022 compact it 736 (ET: N/A)]*


   Answer: Larry Tesler is credited with inventing cut, copy and paste.

   - He developed the idea at Xerox PARC in the 1970s while working on the Gypsy text editor, together with Tim Mott, and he later took it to Apple, where he became chief scientist.
