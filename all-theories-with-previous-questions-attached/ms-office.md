## MS Excel

### MS Excel — Formulas, Functions and Worked Examples

> **MICROSOFT EXCEL is a SPREADSHEET application** that organises data into a grid of **CELLS**, addressed by a **COLUMN letter and a ROW number** (A1, B7, AZ200). Its power comes from **FORMULAS** — expressions that **calculate a result from other cells and recalculate automatically whenever those cells change.**

#### The essential vocabulary

| Term | Meaning |
|---|---|
| **Workbook** | The whole **file** (`.xlsx`) |
| **Worksheet (sheet)** | One **tab** inside the workbook |
| **Cell** | One box, addressed as **column + row** — e.g. **A1** |
| **Range** | A rectangular block of cells — **A1:A4** (a column), **A1:D10** (a block) |
| **FORMULA** | ⭐ **Any expression that begins with `=`** — e.g. `=A1+A2` |
| **FUNCTION** | A **built-in named operation** used inside a formula — `SUM`, `AVERAGE`, `IF`, `VLOOKUP` |
| **Argument** | A value passed to a function, inside its brackets |
| **Operator** | `+ − * / ^` for arithmetic; `= <> > < >= <=` for comparison; `&` to join text |

#### Cell referencing — the concept that causes the most errors

| Type | Written as | Behaviour when the formula is COPIED |
|---|---|---|
| **RELATIVE** | **A1** | ✅ **Both the column and the row ADJUST.** Copying `=A1` one cell down gives `=A2` |
| **ABSOLUTE** | ⭐ **$A$1** | ✅ **NEITHER changes — it always points to A1**, wherever it is copied |
| **MIXED — column locked** | **$A1** | The **column is fixed**, the row adjusts |
| **MIXED — row locked** | **A$1** | The **row is fixed**, the column adjusts |

> **The `$` is the "lock".** The classic use is a **tax rate or exchange rate** held in one cell: `=B2*$F$1` can be copied down a whole column, and every row multiplies its own value by **the same rate in F1**. Without the `$`, the second row would wrongly read F2, the third F3, and so on.

#### The functions most often asked about

| Function | What it does | Example |
|---|---|---|
| **SUM** | Adds a range | `=SUM(A1:A10)` |
| **AVERAGE** | Arithmetic mean | `=AVERAGE(A1:A10)` |
| **COUNT / COUNTA** | Counts **numeric** cells / **non-empty** cells | `=COUNT(A1:A10)` |
| **MAX / MIN** | Largest / smallest value | `=MAX(A1:A10)` |
| ⭐ **LARGE / SMALL** | The **k-th LARGEST / k-th SMALLEST** value | `=LARGE(A1:A10,2)` → the **second** largest |
| **IF** | Conditional result | `=IF(A1>=40,"Pass","Fail")` |
| **SUMIF / COUNTIF / AVERAGEIF** | Aggregate **only the cells meeting a condition** | `=SUMIF(B2:B50,">1000")` |
| **VLOOKUP / XLOOKUP** | **Look a value up in a table** and return a matching column | `=VLOOKUP(A2,$E$2:$G$50,3,FALSE)` |
| **INDEX + MATCH** | A more flexible lookup than VLOOKUP | `=INDEX(C:C,MATCH(A2,B:B,0))` |
| **ROUND / ROUNDUP / ROUNDDOWN** | Rounding | `=ROUND(A1,2)` |
| **CONCATENATE / TEXTJOIN / &** | Join text | `=A1&" "&B1` |
| **LEN / LEFT / RIGHT / MID / TRIM** | Text manipulation | `=LEFT(A1,3)` |
| **TODAY / NOW / DATEDIF** | Dates | `=TODAY()` |
| **IFERROR** | Replace an error with something readable | `=IFERROR(A1/B1,"n/a")` |
| **RANK** | The position of a value within a list | `=RANK(A1,$A$1:$A$10)` |

#### Worked example — the AVERAGE OF THE BEST THREE of four values

> **Cells A1, A2, A3 and A4 contain the power generated by four plants. Write a function in A5 that shows the AVERAGE OF THE BEST THREE power plants.**

**Understanding the requirement:** there are four values; the **average of the best three** means the average of the four **after discarding the WORST (smallest) one**.

**Method 1 — subtract the minimum from the total (the simplest and safest):**
```excel
=(SUM(A1:A4)-MIN(A1:A4))/3
```
> **How it works:** `SUM(A1:A4)` adds all four; `MIN(A1:A4)` finds the **smallest**; subtracting it leaves the **total of the best three**; dividing by 3 gives their average. **This is the answer to write first** — it is short, obvious and cannot go wrong.

**Method 2 — using LARGE, which states the intent explicitly:**
```excel
=AVERAGE(LARGE(A1:A4,1),LARGE(A1:A4,2),LARGE(A1:A4,3))
```
> `LARGE(range, k)` returns the **k-th largest** value, so this averages the 1st, 2nd and 3rd largest — literally "the best three".

**Method 3 — the compact array form (Excel 365 / modern Excel):**
```excel
=AVERAGE(LARGE(A1:A4,{1,2,3}))
```

**A numeric check:**

| Cell | Plant | Generation (MW) |
|---|---|---|
| **A1** | Plant 1 | **120** |
| **A2** | Plant 2 | **150** |
| **A3** | Plant 3 | ⚠️ **90** ← the worst |
| **A4** | Plant 4 | **140** |

```
   SUM(A1:A4) = 120 + 150 + 90 + 140 = 500
   MIN(A1:A4) = 90
   
   (500 − 90) / 3 = 410 / 3 = 136.67
```
> ### ✅ **A5 displays 136.67 MW** — the average of 120, 150 and 140, with the worst plant (90) correctly excluded.
>
> **Verification by Method 2:** LARGE(…,1)=150, LARGE(…,2)=140, LARGE(…,3)=120 → (150+140+120)/3 = 410/3 = **136.67** ✅ — the two methods agree, which is exactly the check to show in an exam.

#### The generalisation worth adding

| Requirement | Formula |
|---|---|
| Average of the **best 3 of N** values | `=AVERAGE(LARGE(range,{1,2,3}))` |
| Average of the **best N−1** (drop the worst one) | `=(SUM(range)-MIN(range))/(COUNT(range)-1)` |
| Average of the **worst 3** | `=AVERAGE(SMALL(range,{1,2,3}))` |
| Average **dropping both the best AND the worst** | `=(SUM(range)-MAX(range)-MIN(range))/(COUNT(range)-2)` |
| Average of values **above a threshold** | `=AVERAGEIF(range,">100")` |
| **Total** of the best three | `=SUM(LARGE(range,{1,2,3}))` |

> ⚠️ **Two practical cautions to mention:**
> 1. **Never hard-code the divisor when the range might change size** — `(SUM(range)-MIN(range))/(COUNT(range)-1)` adapts automatically, whereas `/3` breaks if a fifth plant is added.
> 2. **Blank cells and text behave differently from zeros.** `AVERAGE` **ignores** empty cells and text but **includes** zeros, while `MIN` would return **0** if any cell contained a zero — which would then be treated as the "worst plant" even if that plant simply had no data. For real data, guard with `=IFERROR(...,"")` and consider `AVERAGEIF(range,">0")`.

#### Common Excel errors and their meaning

| Error | Cause |
|---|---|
| **#DIV/0!** | Division by zero or by an empty cell |
| **#VALUE!** | Wrong data type — text where a number is expected |
| **#REF!** | ⚠️ The formula refers to a **cell that has been DELETED** |
| **#NAME?** | A **misspelled function name**, or text not in quotation marks |
| **#N/A** | A **lookup found no match** |
| **#NUM!** | An invalid numeric argument (e.g. `LARGE(A1:A4,9)` when there are only 4 values) |
| **#####** | Not an error — the **column is simply too narrow** to display the value |
