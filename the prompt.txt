Ami tumake govt job er written exam er question dibo. Tumi question guloke categorize korbe, shei category onujayi md file banabe, then shei corresponding md file e oi question ta rakhbe. And oi question ta oi category er kon subcategory te porse sheta oi md file e likhbe. For instance:
Ami tumake 3 ta question dilam jar modhdhe 3tai dhoro C programming theke toh tumi 3ta kei c-programming.md file e likhba , then oi "c-programming.md" file er vitor sub category hote pare, dhori ekta question asche pointer theke, arekta recursion, arekta dynamic programming, toh protita question tar corresponding sub category er niche append hoye jabe. Sub category er nam ta "##" heighlight korbi.  Ekhon jodi already kuno question er corresponding md file thake new md file banabe na, oi existing er vitor tar corresponding sub category er sheshe append hobe. That means tumar main kaaj question gula ke categorize kora, then subcategorize kora. Protita question intact rakhbe, exam tag page number thakbe.
