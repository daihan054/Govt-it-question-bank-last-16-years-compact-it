## Machine Learning & AI Concepts (18)

1. **Which AI application involves teaching a computer to perform a task by example,rather than through explicit programming?** *[Combined Bank Officer (IT) 04.10.2024 compact it 13 (ET: BIBM)]*  
   (a) Unsupervised learning  
   (b) Reinforced learning  
   (c) Supervised learning  
   (d)Machine vision

   answer: c — Supervised learning  
   explanation: Supervised learning trains a model on labelled example pairs, so the machine learns the task from examples instead of hand-written rules.

2. **What is the main goal of reinforcement learning?** *[Combined Bank Officer (IT) 04.10.2024 compact it 13 (ET: BIBM)]*  
   (a) To classify data into categories  
   (b) To optimize a system for maximum efficiency  
   (c) To make prediction based on historical data  
   (d) To learn optimal actions through trial and error

   answer: d — To learn optimal actions through trial and error  
   explanation: An RL agent interacts with an environment and adjusts its policy from reward and penalty feedback to maximise long-term reward.

3. **What does cross-validation mean in AI?** *[Combined Bank Officer (IT) 04.10.2024 compact it 14 (ET: BIBM)]*  
   (a) The process of validating the results of a neural network  
   (b) The process of training a model on multiple datasets  
   (c) The process of splitting data into training and testing sets  
   (d) The technique for evaluating model performance using multiple subsets of data

   answer: d — The technique for evaluating model performance using multiple subsets of data  
   explanation: Cross-validation (e.g. k-fold) splits data into k folds and trains and tests k times, giving a more reliable performance estimate than one split.

4. **What is the process of reducing the dimensionality of data while maintaining itsessential characteristics-** *[Combined Bank Officer (IT) 04.10.2024 compact it 14 (ET: BIBM)]*  
   (a) Gradient Boosting oldeara  
   (b) k-means clustering  
   (c) Principal component Analysis  
   (d) Regression

   answer: c — Principal component Analysis  
   explanation: PCA projects data onto a few orthogonal components that keep most of the variance, cutting dimensions while retaining the essential information.

5. **What does the term 'hyperparameter' refer in AI?** *[Combined Bank Officer (IT) 04.10.2024 compact it 14 (ET: BIBM)]*  
   (a) Parameter learned by the model during training  
   (b) Parameter that define the structure of the model  
   (c) Parameter used to make prediction  
   (d) Parameter related to the loss function

   answer: b — Parameter that define the structure of the model  
   explanation: Hyperparameters (learning rate, number of layers, k in k-NN) are set before training; weights learned during training are ordinary parameters.

9. **What s the axon of neural network do?** *[BCC Assistant Programmer 11.11.2023 compact it 36 (ET: N/A)]*

11. **Which of the following neural networks uses supervised learning?** *[Sonali Bank and BDBL Senior Officer (IT) 25.09.2021 compact it 106 (ET: N/A)]*  
   (a) Multilayer perceptron  
   (b) Self organizing feature map

15. **K nearest neighbor algorithm is part of:** *[Combined 2 Banks Senior Officer (IT) 2020 compact it 172 (ET: N/A)]*

16. **If the class levels of training data set are unknown in machine learning, then it is called:** *[Combined 2 Banks Senior Officer (IT) 2020 compact it 172 (ET: N/A)]*  
   a) classification  
   b) clustering  
   c) association  
   d) reinforcement learning

   answer: b — clustering  
   explanation: With no class labels the algorithm can only group similar records by similarity, which is unsupervised clustering.

17. **Hill climbing search এর প্রধান সমস্যা কোনটি?** *[BPSC Assistant Programmer (Dept. of ICT) 2020 compact it 188 (ET: N/A)]*

   B) Infinite loop  
   C) No Solution

   answer: A — Local Maxima  
   explanation: Hill climbing only moves uphill, so it can stop at a local maximum and never reach the global optimum.
