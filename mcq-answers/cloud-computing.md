## Cloud Computing Fundamentals (14)

1. **What type of computing technology refers to services and applications that typically run on a distributed network through virtualized resources?** *[Bangladesh Bank Assistant Maintenance Engineer 04.02.2023 compact it 23 (ET: BIBM)]*
   (a) Distributed Computing
   (b) Cloud Computing
   (c) Soft Computing
   (d) Parallel Computing
answer: B
explanation: Cloud computing delivers on-demand computing services—including compute power, storage, and applications—over a network using shared, virtualized infrastructure.

2. **Cloud Computing architecture is a combination of ______.** *[Bangladesh Bank Assistant Maintenance Engineer 04.02.2023 compact it 23 (ET: BIBM)]*
   (a) Service-oriented architecture and grid computing
   (b) Utility computing and event-driven architecture.
   (c) Service-oriented architecture and event-driven architecture.
   (d) Virtualization and event-driven architecture.
answer: A
explanation: Cloud computing architecture builds upon Service-Oriented Architecture (SOA) for loose coupling and service delivery combined with Grid Computing for large-scale distributed resource sharing.
